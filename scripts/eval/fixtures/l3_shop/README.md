# shop —— 极简下单计价库

一个小而完整的多模块 Python 库，无第三方依赖。

## 模块职责

| 模块 | 职责 |
|---|---|
| `shop/catalog.py` | 商品目录（只读数据源）：按 SKU 取商品、列全部商品 |
| `shop/pricing.py` | 计价规则：满量折扣、百分比折扣、含税金额 |
| `shop/cart.py` | 购物车：加购、小计、应付合计（调用 pricing） |
| `shop/report.py` | 文本报表：把一个购物车汇总成给人看的清单 |

## 计价规则（业务口径）

- **满量折扣**：满 3 件减 5%，满 5 件减 10%，满 10 件减 15%（按整车件数算，取最高一档）。
- 折后金额再按 6% 计税，四舍五入到分。

## 怎么跑测试

```
python run_tests.py
```

全部通过时打印 `ALL TESTS PASSED`。
